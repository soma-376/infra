HELP
kubernetes_events input plugin

DESCRIPTION
Kubernetes Events

GLOBAL_OPTIONS
tag                                Set a tag for the events generated by this input plugin
                                   > default: default, type: string

log_level                          Specifies the log level for this input plugin. If not
                                   set, the plugin will use the global log level defined
                                   in the 'service' section. If the global log level is
                                   also not specified, it defaults to 'info'.
                                   > default: info, type: string

log_suppress_interval              Allows suppression of repetitive log messages plugins
                                   that appear similar within a specified time interval.
                                   It defaults to 0, which means no suppression.
                                   > default: 0, type: time

routable                           If set to 'true', the data generated by the plugin will
                                   be routable, meaning that it can be forwarded to other
                                   plugins or outputs. If set to 'false', the data will be
                                   discarded.
                                   > default: true, type: boolean

alias                              Sets an alias for the input instance. This is useful
                                   when running multiple instances of the same input
                                   plugin. If no alias is specified, a default name will
                                   be assigned using the plugin name followed by a dot and
                                   a sequence number (e.g., cpu.0, cpu.1).
                                   > default: default, type: string

mem_buf_limit                      Set a memory buffer limit for the input plugin
                                   instance. If the limit is reached, the plugin will
                                   pause until the buffer is drained. The value is in
                                   bytes. If set to 0, the buffer limit is disabled.Note
                                   that if the plugin has enabled filesystem buffering,
                                   this limit will not apply.
                                   > default: 0, type: size

storage.type                       Sets the storage type for this input, one of:
                                   filesystem, memory or memrb.
                                   > default: memory, type: string

storage.pause_on_chunks_overlimit  Enable pausing on an input when they reach their chunks
                                   limit
                                   > default: false, type: boolean

threaded                           Enable threading on an input
                                   > default: false, type: boolean

thread.ring_buffer.capacity        Set custom ring buffer capacity when the input runs in
                                   threaded mode
                                   > default: 1024, type: integer

thread.ring_buffer.window          Set custom ring buffer window percentage for threaded
                                   inputs
                                   > default: (5), type: integer

rate_window                        Set input rate window using a time unit (for example:
                                   1s, 1m, 1h). The computed rate is always published in
                                   per-second units.
                                   > default: 1s, type: time

rate_gate                          Enable input rate gate control.
                                   > default: false, type: boolean

rate_gate.max_bytes                Maximum input byte rate per second before pausing
                                   ingestion.
                                   > default: 0, type: size

rate_gate.max_records              Maximum input record rate per second before pausing
                                   ingestion.
                                   > default: 0, type: integer

rate_gate.backpressure             Apply retry and busy chunk pressure when computing
                                   effective limits.
                                   > default: true, type: boolean

rate_gate.resume_ratio             Hysteresis threshold used for resuming input rate gate.
                                   > default: 0.80, type: double
